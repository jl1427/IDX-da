IDX Exchange - Week 9 Ready-to-Submit Package

Files included:
1. idx_week9_competitive_analysis_tableau_prep.py
2. IDX_Week9_Meeting_Ready_to_Submit.docx

How to use:
1. Put idx_week9_competitive_analysis_tableau_prep.py in the same folder as week7_clean_filtered_sold_dataset.csv.
2. Run: python idx_week9_competitive_analysis_tableau_prep.py
3. The script will create:
   - week9_competitive_transactions_tableau.csv
   - week9_top_100_listing_agents.csv
   - week9_top_100_listing_offices.csv
   - week9_zip_median_close_price_heatmap.csv
   - week9_zip_homes_sold_heatmap.csv
   - week9_competitive_analysis_summary.csv
4. Open Tableau and create/update competitive_analysis.twbx using the generated CSV files.
5. Bring the DOCX meeting guide to explain what you completed and what you are showing.

Note:
The generated CSV files and .twbx workbook are not included because they require your local confidential MLS data.
